# JN-VE-GLOBAL 组件库文档

## 概述

JN-VE-GLOBAL 是基于 Vue 3 + Element Plus + TypeScript 的二次封装组件库，专为江苏金农内部项目开发。

## 使用指南

### 安装
```bash
npm install jn-ve-global
```

### 引入
```typescript
// 完整引入
import JnVeGlobal from 'jn-ve-global'
import 'jn-ve-global/dist/style.css'

app.use(JnVeGlobal)

```
